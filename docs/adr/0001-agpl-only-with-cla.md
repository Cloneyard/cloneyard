# AGPL-3.0-only with a CLA

Cloneyard is licensed under AGPL-3.0-only, so anyone who runs a modified Cloneyard as a network service has to publish their changes. We use "only" rather than "or later": a future AGPL version applies to the code only when the project decides it should. Contributions come in under a Contributor Licence Agreement, because the project needs the right to relicense them: the API and plugin SDK crates will be MIT/Apache-2.0, and a commercial licence has to stay possible.

## Considered options

- **AGPL-3.0-or-later**: a new version published by the FSF would cover the code without the project's decision.
- **DCO instead of a CLA**: lighter for contributors, but it grants no right to relicense, so moving code into a permissive crate would need every author's consent.
